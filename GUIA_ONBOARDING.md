# Guia de Onboarding — FinanceApp

> **Para novos usuários** | Tempo estimado: 5-10 minutos

---

## Visão Geral do Fluxo

```
Tela Inicial → Cadastro → Confirmação → Login → Onboarding (4 passos) → Dashboard
```

---

## Passo a Passo Detalhado

### 1️⃣ Tela Inicial (Boas-vindas)

**O que você vê:**
- Logo do FinanceApp
- Título: "Controle suas finanças"
- Dois botões:
  - **🟦 "Começar"** → Vai para cadastro
  - **⬜ "Já tenho conta"** → Vai para login

**Ação:** Clique em **"Começar"**

---

### 2️⃣ Cadastro

**Opção A: E-mail e Senha**
```
┌─────────────────────────────────┐
│  Nome completo                  │  [____________________]  ← Como quer ser chamado
│  E-mail                         │  [____________________]  ← Seu e-mail principal
│  Senha                          │  [____________________]  ← Mínimo 8 caracteres
│  Confirmar senha                │  [____________________]  ← Digite novamente
│                                 │
│  [🟦 Criar conta]               │
│                                 │
│  ────── ou ──────               │
│                                 │
│  [🔵 Continuar com Google]      │
└─────────────────────────────────┘
```

**Requisitos da senha:**
- Mínimo 8 caracteres
- Pelo menos 1 letra maiúscula
- Pelo menos 1 número
- Pelo menos 1 símbolo (!@#$%^&*)

**Opção B: Google (Recomendado)**
- Clique em "Continuar com Google"
- Escolha sua conta Google
- Autorize o acesso (nome, e-mail, foto)
- **Pronto!** Pula a verificação de e-mail

**Após clicar "Criar conta" (opção A):**
- Tela: **"Verifique seu e-mail"**
- Abra sua caixa de entrada → procure e-mail do FinanceApp
- Clique no botão **"Confirmar meu e-mail"**
- Redireciona para login automaticamente

> **Aparece automaticamente no primeiro login**. Cada passo tem botão "Pular" (exceto Passo 1).

---

#### **Passo 2: Crie sua primeira conta** (Obrigatório)

```
┌─────────────────────────────────┐
│  💰  Onde você guarda seu       │
│      dinheiro?                  │
│                                 │
│  Escolha um tipo:               │
│                                 │
│  [💵] Carteira (dinheiro vivo)  │
│  [🏦] Conta Corrente            │
│  [💰] Poupança                  │
│  [📈] Investimento              │
│  [📦] Outro                     │
│                                 │
│  Nome da conta: [____________]  │  ← Ex: "Nubank", "Carteira"
│  Saldo inicial:  R$ [________]  │  ← Quanto tem HOJE nessa conta
│                                 │
│  [🟦 Criar conta]     [Pular]   │
└─────────────────────────────────┘
```

**Dicas:**
- **Carteira**: dinheiro físico na bolsa/bolso
- **Conta Corrente**: banco do dia a dia (Nubank, Itaú, Bradesco...)
- **Poupança**: conta poupança separada
- **Investimento**: corretora, CDB, Tesouro Direto
- **Saldo inicial**: coloque o valor **real de agora** — o app calcula tudo a partir daqui
- Essa conta vira sua **Conta Principal** (padrão para novas transações)

## Checklist Pós-Onboarding

Marque conforme for fazendo:

- [ ] **Conta criada** e saldo inicial correto
- [ ] **Pelo menos 1 transação** registrada (despesa ou receita)
- [ ] **Entendeu o dashboard** (saldos, gráficos, alertas)
- [ ] **Explorou o menu lateral** (Transações, Contas, Cartões, Orçamentos, Metas, Relatórios, Backups, Configurações)
- [ ] **Ajustou tema** (claro/escuro) em Configurações → Perfil
- [ ] **Configurou notificações** em Configurações → Notificações
- [ ] **Escolheu/planejou seu plano** (Free, Premium ou PRO)

## Próximos Passos Recomendados (Primeira Semana)

| Dia | Ação | Por quê |
|-----|------|---------|
| **Hoje** | Registre 5-10 transações recentes | Cria histórico inicial |
| **Dia 1** | Crie suas contas reais (banco, carteira, poupança) | Saldo consolidado correto |
| **Dia 2** | Cadastre seus cartões de crédito | Acompanha faturas automático |
| **Dia 3** | Crie 2-3 orçamentos (Alimentação, Transporte, Lazer) | Controla gastos por categoria |
| **Dia 4** | Crie 1 meta financeira (Reserva emergência ou sonho) | Motivação visual |
| **Dia 5** | Veja os relatórios (Fluxo de Caixa, Por Categoria) | Entende seus padrões |
| **Dia 6** | Configure backup manual (se Premium) ou veja opções | Segurança dos dados |
| **Dia 7** | Revise tudo, ajuste categorias, convide família (se quiser) | Ajuste fino |

## Dúvidas Comuns no Início

| Dúvida | Resposta Rápida |
|--------|-----------------|
| **"Coloquei saldo errado na conta inicial"** | Edite a conta → altere "Saldo Inicial" → salva. Tudo recalcula. |
| **"Não vejo a opção de backup"** | Só está disponível no **Premium** e **PRO**. Free não tem. |
| **"Quero adicionar meu cônjuge"** | Só o **Master** (você) pode convidar. Vá em Configurações → Usuários → Convidar. |
| **"Meus dados somem se eu trocar de celular?"** | Não! Tudo fica na nuvem. É só logar no novo dispositivo. |
| **"Posso usar no computador e no celular?"** | Sim! É PWA — instala no celular (adicione à tela inicial) e usa no navegador do PC. |
| **"O que acontece se eu passar 50 transações no Free?"** | Fica **somente leitura** — vê tudo, não edita/cria novo. Upgrade libera na hora. |

## Instalando como App (PWA)

### No Android (Chrome/Edge):
1. Abra o FinanceApp no navegador
2. Menu (⋮) → **"Instalar app"** ou **"Adicionar à tela inicial"**
3. Confirme → ícone aparece na gaveta de apps

### No iPhone (Safari):
1. Abra no Safari
2. Botão **Compartilhar** (quadrado com seta ↑)
3. Role para baixo → **"Adicionar à Tela de Início"**
4. Toque em **"Adicionar"**

### No Desktop (Chrome/Edge):
1. Abra no navegador
2. Ícone de **instalação** na barra de endereço (⊕ ou monitor com seta)
3. Clique → **"Instalar"**

> **Vantagens**: Ícone próprio, tela cheia, funciona offline, notificações push (Premium+)
